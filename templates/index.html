PROJECT PROFILE / 05

About PhishLab

A practical email investigation workbench for SOC Analyst L1 learning.

Project objective

Build repeatable, evidence-led email investigation habits.

This project demonstrates how a Python parser can extract selected email headers, message subject, URLs, and IP address strings from .eml files. The Flask interface makes that workflow accessible through a browser.

PythonFlaskEmail parsingURL defangingIncident reportingUnit testing

Known limitations

What this tool does not do.

  • Does not independently verify SPF, DKIM, or DMARC.
  • Does not visit URLs or query external reputation services.
  • Does not execute attachments or scan malware.
  • Does not prove an email is benign or malicious automatically.
  • Uses fictional project examples for demonstration.
ⓘ Use only on email files you are authorized to inspect. Follow your organization’s incident-response procedures.
